# 导航栏问题排查

如果导航栏没有显示，或者新增分类没有出现在顶部导航，请按以下步骤排查。

## 1. 先确认当前实现规则

当前顶部导航不是手工维护的，而是从项目根目录自动生成。

只有同时满足下面条件的一级内容目录，才会出现在顶部导航：

- 目录没有被排除
- 目录下至少存在一篇根级非 `index.md` Markdown 文件

如果一个目录只有子目录而没有根级正文，侧边栏可以生成，但顶部导航不会出现。

## 2. 清除浏览器缓存

可以先强制刷新页面：

- Windows: `Ctrl + Shift + R`
- macOS: `Cmd + Shift + R`

## 3. 检查部署状态

访问 GitHub Actions：

`https://github.com/qdleader/Awesome-AI-Pedia/actions`

确认最新部署是否成功。

## 4. 检查页面源代码和控制台

1. 打开线上站点首页
2. 查看页面源代码，搜索 `VPNavBar`
3. 打开浏览器开发者工具，检查 Console 和 Network 是否有报错

## 5. 尝试访问已知正常页面

可以访问以下路径确认站点本身是否正常：

- `https://qdleader.github.io/Awesome-AI-Pedia/claudeCode/`
- `https://qdleader.github.io/Awesome-AI-Pedia/mcp/`
- `https://qdleader.github.io/Awesome-AI-Pedia/docs/guide/getting-started/`

如果这些页面正常，问题大概率是某个具体导航项或首页组件配置不正确。

## 6. 本地复现

```bash
npm install
npm run dev
```

默认本地地址通常为：

```text
http://localhost:5173/Awesome-AI-Pedia/
```

如果本地正常而线上异常，优先排查缓存、部署产物和托管平台重写规则。

## 7. 检查几个关键文件

- `docs/.vitepress/config.ts`
- `docs/.vitepress/utils/sidebar.ts`
- `docs/.vitepress/components/NavigationCards.vue`

重点看：

- `base` 是否正确
- 目录扫描排除规则是否把目标目录过滤掉了
- 首页快捷卡片是否手工写错了链接

## 常见结论

### 新分类没有出现在顶部导航

原因通常是该目录下没有根级正文 Markdown。

### 首页卡片能看到，但点击 404

原因通常是 `NavigationCards.vue` 里手工写错了链接。

### 线上 404，本地正常

优先检查部署目录、`base` 配置和托管平台的重写规则。
